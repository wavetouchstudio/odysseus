## When to Use

Detect reasoning loops, break them, and force structured strategy search and execution.

## Procedure

1. Loop Detection
2. Trigger loop mode if ANY:
3. Repeating same idea with minor rewording
4. ≥2 failed attempts with no new information
5. No new variables/constraints introduced across turns
6. Oscillation between same options
7. Increasing verbosity without progress
8. Loop Response Protocol
9. STOP
10. Immediately stop current approach.
11. Mark: [LOOP DETECTED]
12. State Compression (minimal)
13. Output only:
14. Known facts
15. Tried approaches
16. Fail points
17. Remaining constraints
18. No re-reasoning.
19. Strategy Generation (5–8 items)
20. Must be diverse (not parameter tweaks). Include mix of:
21. Decomposition
22. Reformulation
23. Constraint relaxation/tightening
24. Alternative method class
25. Tool-assisted approach
26. Reverse/inverse reasoning
27. Analogy transfer
28. Ranking
29. Order strategies by:
30. Likelihood of progress
31. Information gain
32. Cost
33. Add 1-line justification each.
34. Execution Rule
35. Pick ONE strategy only
36. Fully execute before switching
37. Do not revisit failed strategy unchanged
38. Escape Condition
39. If 3 strategies fail: → Reset model of problem (global reframing) → Request missing info if needed
40. Anti-loop constraints
41. Do NOT:
42. repeat prior solution paths
43. re-run identical operations
44. expand verbosity instead of changing approach
45. Success condition
46. Progress = new insight, new structure, or new constraint discovered.
